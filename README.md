# Calculator

A private, offline-first calculator: basic, advanced, financial and programming modes, plus a converter for
currency, length, weight, temperature and many more. Runs on the web (installable), Linux, Windows and Android.

No account, no tracking, no data leaves your device (except the optional currency-rate refresh).

Open it in your browser at https://userofit123.github.io/calculator/ and install it from there, or get the apps from
the [latest release](https://github.com/userofit123/calculator/releases/latest).
